# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：
uv run python -m app.ask "AIE2026 の講座の宿題にある
「3レベル」とは何ですか？"
[model] gemini-3.5-flash-lite
[質問] AIE2026 の講座の宿題にある
「3レベル」とは何ですか？

AIE2026（AIエンジニア育成講座など）の宿題における「3レベル」という言葉は、**受講生のスキルや理解度、または宿題の難易度に合わせて3段階に分かれた課題（レベル1、レベル2、レベル3）**を指している可能性が非常に高いです。

一般的に、AIやプログラミング系の講座で見られる「3レベル構成」には、以下のような意図や内容が含まれます。

### 1. よくある「3レベル」の内訳
* **レベル1（基礎・初級）：**
  * 授業の復習や、用意されたコードをそのまま動かす、穴埋めをするなど、**基本の確認**がメイン。
* **レベル2（応用・中級）：**
  * 基礎を少し発展させ、自分で考えてコードの一部を書き換えたり、少し新しい条件を追加したりする**実践的な課題**。
* **レベル3（発展・上級）：**
  * 自力でゼロからコードを書く、応用的な機能を実装する、より高度なアルゴリズムやプロンプトエンジニアリングを試すなど、**応用力・思考力を試すチャレンジ課題**。

---

### 2. どう取り組むべきか？（確認すべきこと）
もしAIE2026のガイダンスや教材で指示を見落とした場合は、以下の点を確認してみてください。

1. **「全員が3つすべてやる」のか、「自分のレベルに合わせて選ぶ（選択式）」のか？**
   * 講座によっては「レベル1は全員必須、レベル2・3は挑戦したい人のみ」というルールになっていることがあります。
2. **どこに基準があるか？**
   * プログラミング未経験者は「レベル1」から、経験者は「レベル2や3」から挑戦するように指定されている場合があります。

---

**【確実な確認方法】**
もし手元の資料（Slack、Discord、LMSの掲示板、Notionなど）で「3レベル」についての詳細な定義が見つからない場合は、**講座の運営事務局やメンター、講師に「宿題の3レベルとは、すべて提出する必要がありますか？ それとも自分のレベルに合わせて選ぶのでしょうか？」と質問する**のが一番確実で安心です。

- 用語集の正しい意味と比べて気づいたこと：モデルは「理解度や難易度に応じた3段階」と推測していたが、実際は「基礎（講義内容の確認）・実装（自分でコードを書く）・発展（調査や試行）」という取り組み方の選択肢だった。講座固有の情報を知らないモデルが、一般論を事実のように補ってしまうことに気づいた。

## 宿題

- 取り組んだレベル：実装
- やったこと：`app/ask.py` に `--chat` オプションを追加した。1つの Gemini chat セッションを使い続け、質問を続けて送れるようにした。`q`、`quit`、`exit`、`終了` のいずれかで終了する。最初の質問を引数に渡した場合は、その質問から会話を始める。
- 結果：`uv run python -m app.ask --chat` で対話を開始できる。従来どおり質問を引数に渡す使い方も残した。
- 使ったモデル：`gemini-3.5-flash-lite`（既定モデル。会話モードのテストではAPIを呼ばず、モックを使用。）
- 気づき・疑問：同じ chat セッションを使うことで会話の文脈を引き継げる。一方、会話が長くなるほど過去の会話も含めて処理されるため、入力トークン数やレート制限への影響を今後確認したい。
